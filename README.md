# 潜行绮遇 · Dive Into Wonder

**当前源码版本 1.2.0** · [版本说明](./CHANGELOG.md) · [GitHub Releases](https://github.com/Haeiou414/DiveIntoWonder/releases)

像素风科幻潜水探索游戏。驾驶潜艇穿过五层海域，采集样本、记录生物、收集合金。回到浮岛基地，把样本组合成生命回路，选择突变并培育仿生模块。用科研与改装支持下一次下潜，向 11,000 米深海进发。

1.2 加入 **共鸣演化舱**，通过 5×5 回路、三次脉冲与突变选择培育五类可装备模块。生物图鉴扩展到 **30 个条目**，具有独立形态、生态行为和可查询的科学分类。蝠鲼号可远距观测并获取高完整度样本。

## 开始游戏

需要 Node.js 18 或更高版本，可直接启动。

```sh
git clone https://github.com/Haeiou414/DiveIntoWonder.git
cd DiveIntoWonder
npm start
```

在浏览器打开 **http://127.0.0.1:5173**。也可以在 VS Code 中运行「潜行绮遇 · 本地游戏」任务。使用 `PORT=8080 npm start` 可自定义端口。

通过 HTTP 服务器运行 ES 模块。Chrome、Edge、Firefox、Safari 的近期版本均支持使用的 Canvas 2D、Web Audio 与 HTML Dialog API。可离线游玩。在线时可选加载 Google Fonts，无法连接时使用系统字体。

点击右上角 **开启音乐**，播放包含旋律、和弦、低音与轻节拍的原创八小节主题。日光带、暮光带、深海、科研站和港口使用不同编曲。按钮旁可调整音量。音乐默认关闭，首次点击才启用音频，页面隐藏时暂停。水声和采集、升级等音效保留。

## 玩法循环

1. 驾驶合适的载具寻找生物群落、岩壁矿脉与洞穴，靠近后按 E 捕获或采集。新物种立刻记入图鉴，回港结算信用点、合金和少量初步科研点，同时将生物样本存入冷藏库。
2. 电量、舱内负载限制单次下潜。超过额定安全深度会损伤艇壳。电量耗尽或艇壳失效时自动牵引回港，保留样本。
3. 完成采集、深度与科研委托，领取信用点、合金与科研点。点击委托右上角箭头查看全部任务。
4. 回港后选择 1–3 份样本开始共鸣实验，旋转回路，把脉冲送到目标器官。组合样本、选择突变、分配能量，培育下一次下潜的仿生模块。
5. 制作载具、升级耐压艇壳、电池、样本舱与推进器。三艘载具可同时拥有，通用改装全舰队共享。研究已捕获生物的基因，永久提升视野、速度、耗电效率、容量、声呐和修复能力。
6. 收录 3 / 6 / 10 / 14 / 18 / 24 / 30 个生物条目可领取图鉴里程碑奖励。完成探索与科研目标还可解锁舰队涂装。发现最深处「世界尽头的光」完成主线，之后仍可自由收集。

### 共鸣演化舱

在港口从冷藏库选取一份样本启动实验，在第一次脉冲前可再加入两份。旋转 **5×5** 网格上的连接片，将中心胚核连到外侧器官。亮线和能量数字实时显示下一次脉冲的结果，P 可播放免费预演。实验由玩家操作推进，可自由思考。

- 每轮共释放 **三次脉冲**。前两次释放后各选一次突变，再调整回路，继续为器官充能。
- 分叉会分配能量，每经过一格会产生损耗。相应样本亲和可增加器官收益，跨动物门的组合增加初始能量。
- 完整样本每份额外增加 5 点初始能量，并把突变选项从三选一增加到四选一。
- 突变可提高初始能量、减少损耗、改善分叉传递、放大已积累能量或增强亲和。每种突变在一次实验中最多选择一次，回路方向和突变会共同改变最终成果。
- 第三次脉冲后选择一个已充能器官培育模块。能量大于 0 可获得Ⅰ阶，达到 13 / 90 可获得Ⅱ / Ⅲ阶，并结算科研点与信用点。完整样本和多样本共生支持高阶演化。

| 模块 | 对下潜的影响 |
| --- | --- |
| 折光膜 | 提升探照视野 |
| 喷流肌束 | 提升航行速度 |
| 等压骨架 | 增加安全深度 |
| 回声心核 | 延长声呐回波、缩短冷却 |
| 自愈纤维 | 在安全深度缓慢修复艇壳 |

每类模块永久保存已培育的最高阶版本，港口可选择一个装备，当前装备随驾驶载具生效。六项基础基因适应可以继续研究。实验结算前可撤销，退回投入的全部样本及完整度，重新尝试其他组合。

### 海域与载具

| 海域 | 深度 |
| --- | --- |
| 日光带 | 0–200 m |
| 暮光带 | 200–1,000 m |
| 午夜带 | 1,000–4,000 m |
| 深渊带 | 4,000–6,000 m |
| 冥渊带 | 6,000–11,000 m |

- **萤蛾号**是洞穴侦察艇，初始安全深度 650 米。速度最快、舱容较小，唯一能进入狭窄洞喉的艇型。V 触发短距冲刺，仍会被岩壁阻挡。
- **蝠鲼号**是生物科研艇，初始安全深度 2,600 米。Q 发出半径 1,150 米、持续 8 秒的低耗声呐，V 优先锁定不同物种的至多 5 个已探明活体。在 18 秒内按 E 远距非侵入采样，获得轻负载完整样本与生态记录。个体继续在栖地活动，每个个体每航次采样一次。艇体适于开阔水域。
- **鲸落号**是采矿支援母舰，初始安全深度 6,500 米。速度较慢、货舱较大，采矿产出更高。V 连锁采集附近可见岩脉。可以停泊并释放萤蛾号。

释放小艇时，电量从母舰有限的剩余储备转移，部署与接驳也会耗电。小艇使用自身货舱，母舰保留原有货物，两者合计仍受母舰总容量限制。距母舰 **500 米内**享有母舰耐压保护，超出后恢复小艇自身耐压。返回母舰 **120 米内且通视**时按 F 接驳，将样本及剩余电量带回。

侧壁洞穴位于 **440 米「珊瑚密室」**、**2,400 米「回声晶窟」**、**5,300 米「熔光裂隙」**。岩壁会阻挡移动、照明与采集。寻找洞口并驾驶萤蛾号进入，可取得洞内样本。深处洞穴适合先由母舰接近，再释放小艇探索。

午夜带以下，视野仅限近艇光圈与朝向灯束。声呐临时标记附近的生命、矿脉和生态热点，并显出地形回声。回声随时间消退。岩石遮挡灯光与采集，矿物固定在岩壁或洞底。深海水层的生物较稀疏，更多生命聚集在鲸落、热泉与遗迹附近，可依靠声呐导航寻找。

### 生物图鉴与科学原型

30 个图鉴条目覆盖 6 个动物门，提供 10 个类群筛选，包括辐鳍鱼类、软骨鱼类、头足类、腹足类、钵水母、水螅类、栉水母、八放珊瑚、甲壳类和棘皮动物。详情显示学名、门、纲、目、科、生态和行为。分类于 2026-11-12 按 WoRMS 官方记录核对，每个条目提供对应名录链接。[WoRMS 海洋物种名录](https://www.marinespecies.org/)

每个条目具有独立像素轮廓与动画，世界行为包括集群、巡游、漂浮、搏动、喷射、底栖和定点停驻。玻璃虾虎鱼的小群转向、栉水母的纵向梳板、海笔的长柄息肉、三脚鱼的支撑鳍条和海参的管足各有表现。生态与形态参考了研究机构的资料。[MBARI 深海动物资料](https://www.mbari.org/education/animals-of-the-deep/)

游戏相遇区间参考原型的观测深度，并按五层海域组织。小飞象章鱼采用 *Grimpoteuthis* 属级原型，其冥渊区间对应鉴定到属的深海观测。图鉴中的科学原型与生态记录可供进一步阅读，配色、视觉尺度、中文别名及共鸣能力采用科幻设计。[小飞象章鱼介绍](https://ocean.si.edu/ocean-life/invertebrates/grimpoteuthis-dumbo-octopus)、[冥渊章鱼观测研究](https://link.springer.com/article/10.1007/s00227-020-03701-1)

旧存档的 `ghost_whale` 条目现在对应海参 *Scotoplanes globosa*，`leviathan` 对应大型端足类 *Alicella gigantea*。发现进度沿用旧标识，名称、图像与生态更新为相应原型。绒伞章鱼采用 WoRMS 当前接受名 *Insigniteuthis albatrossi*。[海参分类](https://www.marinespecies.org/aphia.php?p=taxdetails&id=148773)、[端足类分类](https://www.marinespecies.org/aphia.php?p=taxdetails&id=488208)、[绒伞章鱼分类](https://www.marinespecies.org/aphia.php?p=taxdetails&id=1813559)

## 存档

进度通过浏览器 `localStorage` 自动保存。刷新页面会安全回港，自动结算尚未入库的样本。冷藏库存、样本完整度、生命回路、脉冲能量、突变选择、模块、生态记录、洞穴发现和各载具涂装也会保存。重新进入演化舱可继续当前实验。不同浏览器、地址和端口的存档相互独立。

兼容 1.0 和 1.1 存档，沿用原有 18 个物种标识，继承载具、基因、图鉴与探索进度。1.1 科研工位中的未完成样本会退回冷藏库。1.0 已结算的历史样本保持原有结算结果，升级后带回新样本即可开始共鸣实验。

右上角等级按钮可查看航行记录，并通过二次确认清除存档。使用浏览器隐私模式或禁止站点存储时，自动存档可能不可用。请避免同时在多个标签页运行同一个存档。

## 开发与验证

```sh
npm test       # 游戏逻辑、世界碰撞、共鸣实验、物种数据与音乐生命周期测试
npm run check  # 全部运行时 JavaScript 模块与本地服务器的语法检查
```

- [engine.js](./engine.js) 游戏状态、模拟、进度与存档。
- [data.js](./data.js) 配置生物、载具、海域、科研及奇观。
- [taxonomy.js](./taxonomy.js) 保存科学原型分类、WoRMS 标识与来源链接。
- [species-art.js](./species-art.js) 绘制各物种独立像素轮廓与动画。
- [bio-modules.js](./bio-modules.js) 定义五类仿生模块与三级效果。
- [world.js](./world.js) 峡谷与洞穴几何、载具碰撞和视线遮挡。
- [renderer.js](./renderer.js) 低分辨率离屏 Canvas 像素绘制、深海光照与特效。
- [app.js](./app.js) 中文界面、键盘与触屏输入。
- [research-shift.js](./research-shift.js) 管理回路、能量传播、突变、样本流转和演化结算。
- [research-view.js](./research-view.js) 提供演化舱操作界面与脉冲动画。
- [audio.js](./audio.js) Web Audio 原创场景音乐、环境音及音效。
- [styles.css](./styles.css) 响应式布局。
- [server.mjs](./server.mjs) 零依赖静态开发服务器，默认仅监听本机。

画面、图标和声音均由项目代码生成，使用零依赖原生 JavaScript 运行。
