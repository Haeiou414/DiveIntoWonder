# 潜行绮遇 · Dive Into Wonder

**版本 1.0.0** · [版本说明](./CHANGELOG.md) · [GitHub Releases](https://github.com/Haeiou414/DiveIntoWonder/releases)

像素风科幻潜水探索游戏。驾驶潜艇穿过五层海域，捕获生物、收集合金，在科研与载具改装之间切换，向 11,000 米深海进发。

## 开始游戏

需要 Node.js 18 或更高版本，无需安装依赖：

```sh
git clone https://github.com/Haeiou414/DiveIntoWonder.git
cd DiveIntoWonder
npm start
```

在浏览器打开 **http://127.0.0.1:5173**。也可以在 VS Code 中运行「潜行绮遇 · 本地游戏」任务。自定义端口：`PORT=8080 npm start`。

使用 HTTP 服务器运行，不能直接以 `file://` 打开 ES 模块。Chrome、Edge、Firefox、Safari 的近期版本均支持使用的 Canvas 2D、Web Audio 与 HTML Dialog API。可离线游玩；在线时可选加载 Google Fonts，无法连接时使用系统字体。

## 操作

| 操作 | 键位 |
| --- | --- |
| 驾驶 | WASD / 方向键 |
| 捕获附近生物、采集矿物 | E |
| 声呐探测、扩大视野 | Q |
| 加速，额外耗电 | Shift |
| 随时安全返航 | R |
| 母舰释放 / 接驳子艇 | F |
| 暂停 / 继续 | 空格 / Esc |

触屏设备使用左下角方向键与底部动作按钮。点击右上角声音按钮可开启合成水声和游戏音效，默认静音。进入船坞、科研或图鉴页面时暂停下潜。

## 玩法循环

1. 靠近生物或闪光矿石，按 E 捕获或采集。新物种立刻记入图鉴，样本收益在回港时结算。
2. 电量、舱内负载限制单次下潜；超过额定安全深度会损伤艇壳。无氧气、饥饿机制。电量耗尽或艇壳失效时自动牵引回港，保留样本。
3. 完成采集、深度与科研委托，领取信用点、合金与科研点。点击委托右上角箭头查看全部任务。
4. 回港制作载具、升级耐压艇壳、电池、样本舱与推进器。三艘载具可同时拥有，通用改装全舰队共享。
5. 研究已捕获生物的基因，永久提升视野、速度、耗电效率、容量、声呐和修复能力。
6. 收录 3 / 6 / 10 / 14 / 18 种生物可领取图鉴里程碑奖励。发现最深处「世界尽头的光」完成主线，之后仍可自由收集。

### 海域与载具

| 海域 | 深度 |
| --- | --- |
| 日光带 | 0–200 m |
| 暮光带 | 200–1,000 m |
| 午夜带 | 1,000–4,000 m |
| 深渊带 | 4,000–6,000 m |
| 冥渊带 | 6,000–11,000 m |

- **萤蛾号**：轻巧探索艇，初始安全深度 650 米。
- **蝠鲼号**：科研巡航艇，初始安全深度 2,600 米，较大采集范围、低耗声呐。
- **鲸落号**：深海母舰，初始安全深度 6,500 米，可释放萤蛾号，共享耐压与货舱；返回母舰 320 米内按 F 接驳。

共 18 种生物、7 处奇观、6 项基因适应。巨型鲸类与鱿类的捕获代表采集其活性组织样本。

## 存档

进度通过浏览器 `localStorage` 自动保存。刷新页面会安全回港，自动结算尚未入库的样本。不同浏览器、地址和端口的存档相互独立。

右上角等级按钮可查看航行记录，并通过二次确认清除存档。使用浏览器隐私模式或禁止站点存储时，自动存档可能不可用。请避免同时在多个标签页运行同一个存档。

## 开发与验证

```sh
npm test       # Node 原生测试：采集、回港、存档、科研、升级、母舰、任务等
npm run check  # JavaScript 语法检查
```

- [engine.js](./engine.js)：游戏状态、模拟、进度与存档。
- [data.js](./data.js)：生物、载具、海域、科研及奇观配置。
- [renderer.js](./renderer.js)：低分辨率离屏 Canvas 像素绘制、深海光照与特效。
- [app.js](./app.js)：中文界面、键盘与触屏输入。
- [audio.js](./audio.js)：Web Audio 程序化合成环境音及音效。
- [styles.css](./styles.css)：响应式布局。
- [server.mjs](./server.mjs)：零依赖静态开发服务器，默认仅监听本机。

画面、图标和声音均由项目代码生成，不依赖外部游戏素材或构建工具。
