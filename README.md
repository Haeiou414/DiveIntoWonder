# 潜行绮遇 · Dive Into Wonder

**当前源码版本 1.1.0** · [版本说明](./CHANGELOG.md) · [GitHub Releases](https://github.com/Haeiou414/DiveIntoWonder/releases)

像素风科幻潜水探索游戏。驾驶潜艇穿过五层海域，捕获生物、收集合金；回到浮岛基地，亲自完成培养、分析与报告交付。用科研与改装支持下一次下潜，向 11,000 米深海进发。

1.1 新增可操作的 **90 秒科研值班**、有碰撞与遮挡的侧壁洞穴、三种载具专长、有限供电的母舰支援、任务涂装，以及随场景变化的原创合成音乐。

## 开始游戏

需要 Node.js 18 或更高版本，无需安装依赖：

```sh
git clone https://github.com/Haeiou414/DiveIntoWonder.git
cd DiveIntoWonder
npm start
```

在浏览器打开 **http://127.0.0.1:5173**。也可以在 VS Code 中运行「潜行绮遇 · 本地游戏」任务。自定义端口：`PORT=8080 npm start`。

使用 HTTP 服务器运行，不能直接以 `file://` 打开 ES 模块。Chrome、Edge、Firefox、Safari 的近期版本均支持使用的 Canvas 2D、Web Audio 与 HTML Dialog API。可离线游玩；在线时可选加载 Google Fonts，无法连接时使用系统字体。

## 操作

| 操作 | 键位 |
| --- | --- |
| 驾驶 | WASD / 方向键 |
| 捕获附近生物、采集矿物 | E |
| 声呐探测、标记短时回声 | Q |
| 使用当前载具专长 | V |
| 加速，额外耗电 | Shift |
| 随时安全返航 | R |
| 母舰释放 / 接驳子艇 | F |
| 暂停 / 继续 | 空格（探索时也可用 Esc） |
| 科研站：温控校准 / 培养完成后移交 | 1 |
| 科研站：锁定光谱 / 分析完成后移交 | 2 |
| 科研站：交付已完成解码的报告 | 3 |

触屏设备使用左下角方向键与底部动作按钮。科研报告的三个基因符号按画面提示顺序点击。进入船坞、科研值班、基因实验室或图鉴页面时暂停下潜；离开科研值班页面会暂存工位并暂停值班计时。

点击右上角 **开启音乐**，播放包含旋律、和弦、低音与轻节拍的原创八小节主题。日光带、暮光带、深海、科研站和港口使用不同编曲；按钮旁可调整音量。音乐默认关闭，首次点击才启用音频，页面隐藏时暂停；水声和采集、升级等音效保留。

## 玩法循环

1. 驾驶合适的载具寻找生物群落、岩壁矿脉与洞穴，靠近后按 E 捕获或采集。新物种立刻记入图鉴，回港结算信用点、合金和少量初步科研点，同时将生物样本存入冷藏库。
2. 电量、舱内负载限制单次下潜；超过额定安全深度会损伤艇壳。无氧气、饥饿机制。电量耗尽或艇壳失效时自动牵引回港，保留样本。
3. 完成采集、深度与科研委托，领取信用点、合金与科研点。点击委托右上角箭头查看全部任务。
4. 回港后开始科研值班，利用三台设备并行处理样本。准确操作、连续精确交付和匹配专项委托可增加科研与信用点收益。
5. 制作载具、升级耐压艇壳、电池、样本舱与推进器。三艘载具可同时拥有，通用改装全舰队共享。研究已捕获生物的基因，永久提升视野、速度、耗电效率、容量、声呐和修复能力。
6. 收录 3 / 6 / 10 / 14 / 18 种生物可领取图鉴里程碑奖励。完成探索与科研目标还可解锁舰队涂装。发现最深处「世界尽头的光」完成主线，之后仍可自由收集。

### 科研值班

每班最长 **90 秒**，需要在港口拥有至少一份冷藏样本。

| 工位 | 操作 |
| --- | --- |
| 恒温培养槽 | 装入样本，培养进度到 35–80% 时校准温控；培养完成后移交。 |
| 光谱分析仪 | 指针进入中央绿色区间时锁定光谱；分析完成且校准成功后生成报告。 |
| 基因报告终端 | 按提示顺序点击三个符号，再交付报告。 |

移交后即可给上游设备装入下一份样本，让三台设备同时工作。错误校准或序列会降低质量，等待过久也会扣减质量；重新操作即可继续，不会直接销毁样本。高质量交付积累连击，鱼类与水母专项交替出现。

每份报告交付时立即结算奖励，同一样本只消耗一次。计时结束或提前交班会把所有未完成样本退回冷藏库。离开科研站、打开弹窗或隐藏页面时暂停计时，重新进入后继续当前工位。

### 海域与载具

| 海域 | 深度 |
| --- | --- |
| 日光带 | 0–200 m |
| 暮光带 | 200–1,000 m |
| 午夜带 | 1,000–4,000 m |
| 深渊带 | 4,000–6,000 m |
| 冥渊带 | 6,000–11,000 m |

- **萤蛾号**：洞穴侦察艇，初始安全深度 650 米。速度最快、舱容较小，唯一能进入狭窄洞喉的艇型；V 触发短距冲刺，仍会被岩壁阻挡。
- **蝠鲼号**：生物科研艇，初始安全深度 2,600 米。拥有更大的采集范围、低耗声呐和 8 秒声呐探测时间；V 标记附近生物，采集后获得额外科研点。不能进入洞穴。
- **鲸落号**：采矿支援母舰，初始安全深度 6,500 米。速度较慢、货舱较大，采矿产出更高；V 连锁采集附近可见岩脉。可以停泊并释放萤蛾号。

释放小艇时，电量从母舰有限的剩余储备转移，部署与接驳也会耗电。小艇使用自身货舱，母舰保留原有货物，两者合计仍受母舰总容量限制。距母舰 **500 米内**享有母舰耐压保护，超出后恢复小艇自身耐压；返回母舰 **120 米内且通视**时按 F 接驳，将样本及剩余电量带回。

侧壁洞穴位于 **440 米「珊瑚密室」**、**2,400 米「回声晶窟」**、**5,300 米「熔光裂隙」**。岩壁会阻挡移动、照明与采集；寻找洞口并驾驶萤蛾号进入，可取得洞内样本。深处洞穴适合先由母舰接近，再释放小艇探索。

午夜带以下，视野仅限近艇光圈与朝向灯束。声呐临时标记附近的生命、矿脉和生态热点，并显出地形回声；回声随时间消退。岩石遮挡灯光与采集，矿物固定在岩壁或洞底。深海水层的生物较稀疏，更多生命聚集在鲸落、热泉与遗迹附近，可依靠声呐导航寻找。

### 舰队涂装

| 涂装 | 解锁条件 |
| --- | --- |
| 远航原色 | 初始解锁 |
| 珊瑚余晖 | 驾驶萤蛾号进入珊瑚密室 |
| 极光实验室 | 科研值班累计成功交付 10 份报告 |
| 深渊星轨 | 领取抵达 5,000 米的深潜委托奖励 |

解锁后在船坞选择涂装，各载具的选择分别保存。涂装只改变外观。

共 18 种生物、7 处奇观、6 项基因适应。巨型鲸类与鱿类的捕获代表采集其活性组织样本。

## 存档

进度通过浏览器 `localStorage` 自动保存。刷新页面会安全回港，自动结算尚未入库的样本。冷藏库存、进行中的科研工位、洞穴发现和各载具涂装也会保存；重新进入科研站可继续未完成的值班。不同浏览器、地址和端口的存档相互独立。

兼容 1.0 存档，保留原有载具、基因、图鉴与探索进度。1.0 中已经结算的历史样本不会补发为冷藏库存；升级后继续下潜，带回新样本即可开始科研值班。

右上角等级按钮可查看航行记录，并通过二次确认清除存档。使用浏览器隐私模式或禁止站点存储时，自动存档可能不可用。请避免同时在多个标签页运行同一个存档。

## 开发与验证

```sh
npm test       # 游戏逻辑、世界碰撞、科研值班、音乐调度与生命周期测试
npm run check  # 全部运行时 JavaScript 模块与本地服务器的语法检查
```

- [engine.js](./engine.js)：游戏状态、模拟、进度与存档。
- [data.js](./data.js)：生物、载具、海域、科研及奇观配置。
- [world.js](./world.js)：峡谷与洞穴几何、载具碰撞和视线遮挡。
- [renderer.js](./renderer.js)：低分辨率离屏 Canvas 像素绘制、深海光照与特效。
- [app.js](./app.js)：中文界面、键盘与触屏输入。
- [research-shift.js](./research-shift.js)：科研值班流程、样本流转、质量与结算。
- [research-view.js](./research-view.js)：三工位操作界面与实时反馈。
- [audio.js](./audio.js)：Web Audio 原创场景音乐、环境音及音效。
- [styles.css](./styles.css)：响应式布局。
- [server.mjs](./server.mjs)：零依赖静态开发服务器，默认仅监听本机。

画面、图标和声音均由项目代码生成，不依赖外部游戏素材或构建工具。
